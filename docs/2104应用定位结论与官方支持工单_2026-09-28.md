## 五、为什么你在 UI 里找不到它 —— 根因链（5 Why）

1. **为什么列表里没有 2104？** → 因为平台侧 2104 的 app 记录已被删除。
2. **怎么证明被删了？** → 09-28 我对它原目录 `osaka-house-publish/app_local` 走正规 deploy，平台原文报错：*"The app this directory was previously published to has been deleted on the server. Re-deploying to it is not possible…"*，返回的 appId 正是 `wbapp_L8M4tyzslRfAA0IWoy29Iz`。
3. **为什么删了还能访问 2104？** → 沙箱进程还活着（是你今早在 UI 把它重启拉起来的），但**发布系统里的记录没了** ⇒ 现在 2104 是「活着的孤儿」：能访问、不能更新。
4. **为什么记录会被删？** → 与 09-28 凌晨那次 P0 事故同源：`selfrestart` 把服务打成 504 失联后，平台把"失联 app"的发布记录清掉了。
5. **为什么记录没了就不能重建？** → 平台的 deploy 按"目录→app"绑定。原记录被删后，再对该目录 deploy **只能新建一个 app（换新子域）**，直接违反你的「2104 地址绝不变更」死命令 ⇒ 所以我停手，没做。
