## 2. 根因（不是"某一行写错"，是"词典有缺口 + 没门禁"）

用真实库（`data/jproperty.db`，2638 行带详情）× 逐行复现坐实：

1. **字段词典漏收录。** `web/static/fieldmap.js` 的 `FIELD_CN` 少了 `ward` / `unit_price_sqm` / `unit_price_tsubo` / `has_photo` / `has_floorplan` / `has_map`；
   而当时写死的规则是 **「未收录的键 → 保留原始键」**（原注释："宁可露出原键便于补词表"）→ 英文键直接上屏。
2. **三处渲染各有一份自己的跳过清单**，互相不同步：
   - `search.html` 的 `fillDetail()`（查询页展开区，走 JS）；
   - `app.py` 的 `_detail_pairs()`（详情页，走 Python）；
   - `compare.html` 的 `extraKeys()`（对比页，走 JS）。
3. **内部文件键也会漏。** `pdf_url` / `pdf_path` 属抓取内部字段，`app.py` 的 `_CORE_KEYS` 只挡住了 `pdf_path`，`pdf_url` 没挡。
4. **值也没本地化。** `has_*` 直接显示 0/1；`㎡単価` 走 `int(v)//10000` → **5,632 円/㎡ 显示成「0 万円/㎡」**（真 bug）；REINS 枚举（専任/近商/公開中）原样上屏。

> 为什么"之前说过却没改"：**没有任何门禁会把这件事拦住**——改完没人拿全库键跑一遍，漏的键就会一直漏。这次把门禁补上了（见 §4）。

## 3. 修复内容

### 3.1 规则反转（硬规则，写进 `fieldmap.js` 头部注释）
**未收录的键 = 不显示 + 控制台告警**（旧规则"保留原始键"作废）。
宁可少显示一个字段，也绝不把后台机器语言露给客户；缺键由门禁脚本红着脸逼你补词典。

### 3.2 一处词典、三处共用
`fieldmap.js` 新增 `fieldSkip(k)` / `fieldLabel(k)` / `fieldValue(k,v)`；三处渲染全部改为调用它们，删掉各自的硬编码清单。

### 3.3 值本地化表（取值来自真实库全量统计，不靠猜）

| 字段 | 原样 | 现在 |

| `unit_price_sqm` / `unit_price_tsubo` | `9686` | **9,686 円/㎡** / 円/坪（＜1万用円，≥1万用万円） |
