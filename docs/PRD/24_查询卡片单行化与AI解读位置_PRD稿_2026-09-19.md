### 2.1 R-UI-1 实现口径

- 纯模板改动：`detail.html` 中 `pdfCard`（:106，受 `{% if row.pdf_path %}` 包裹）与 `aiCard`（:118）两块**互换位置**即可（已实施：PDF 块上移、AI 块下移）。
- 不受影响项：`/api/ai/<番号>` 异步加载、`aiRegenerate()`、`loadAI()` 时序（AI 卡片无论在哪都是异步填充）、PDF iframe。
- 头卡里那个「打开本地 PDF」跳转按钮（`:58-61`）**保留不动**——它与嵌入展示的 pdfCard 职责不同（新开标签页 vs 页内阅读）。

### 2.2 R-UI-2 交互细节

| 项 | 设计 | 备注 |
|---|---|---|
| 按钮形态 | 建议小号 ghost 胶囊（与 `qcmp` 同风格），文案可缩写：「本地 PDF」「详情页」 | 收成一行后空间紧张，图标 + 悬浮提示亦可 |
| 无 PDF 房源 | **待拍板**：A. 按钮置灰（位置稳定不跳动，推荐）｜ B. 不渲染 | 现状展开区是"不渲染" |
| 点击行为 | 「本地 PDF」新标签打开 `pdf_url`；「详情页」新标签打开 `/p/<番号>`；**不触发行展开**（stopPropagation） | 与 `toggleCompare` 同套路 |
| 待补详情房源（`has_detail === false`） | 「本地 PDF」同样按 pdf_url 有无处理；「详情页」照常可点 | 待补房源通常无 PDF |
| 与展开区关系 | 展开区 `dactions` 的两个按钮**保留**（展开后位置顺手不变） | 也可后续去重，待拍板 |

### 2.3 R-UI-3 单行化方案候选

4 行信息总量 ≈ 20 个字段，硬收一行必然要**取舍或降级**。三个候选：

| 方案 | 做法 | 优点 | 代价 |
|---|---|---|---|
| **A. 升级简洁模式为默认**（推荐起步） | 以 `renderCompactItem` 为基础：补「駅」「坪単価」「番号」与 R-UI-2 两按钮，默认进入 compact | 改动最小、已有验证；详细模式仍可一键切回 | 单行放不下的字段（築年/階/図照/画像枚数）进悬浮 title 或展开区 |
| **B. 详细模式原地压缩** | `renderFullItem` 的 4 个 div 合并为 1 个 flex 行：地址+价格占主、次要字段小字号灰字、放不下自动省略号 | 一处渲染、不改变现有切换逻辑 | 字段取舍需拍板；窄屏更挤；改动面比 A 大 |
| **C. 表格化一览** | 结果列表改 REINS 风格表格（列头固定：对比/状態/地址/价格/面積/間取り/駅/区/単価/取得日/操作） | 信息密度最高、对齐整齐 | 改动最大；移动端需另处理；偏离现有卡片交互 |

> 任意方案都须保留：点击行展开详情、加入对比、降价/涨价徽标、新增/变更 tag（这些是既有一等公民）。

## 3. 验收标准

- **R-UI-1**：打开任一 `/p/<番号>`（如 `300137472761`），页面自上而下 = 详细信息 → 房源図面 PDF → AI 解读 → 变更历史；AI「重新生成」、PDF 翻页缩放打印均正常。
- **R-UI-2**：不展开任何卡片，即可在每行看到「本地 PDF」「详情页」两按钮；点击**不**触发行展开；有 PDF 的行可打开 PDF，无 PDF 行按拍板口径（置灰/隐藏）表现一致。
- **R-UI-3**：默认视图下每套房源卡片只占**一行**；单行内至少含：加入对比、价格、面積、間取り、駅、区、降价徽标、新增/变更 tag、R-UI-2 两按钮；四语言（简/繁/EN/日）不溢出、不换行错位。
- 回归：排序、分页、对比栏摘要、`/api/query` 各筛选条件均不受影响。

## 6. 上线复核教训（2026-09-19 · 小巴中转验证层复核）

- **🔴 AI 主笔 PRD 易漏的真 bug**：PRD v1.0.3 自称「三需求全闭环、默认单行」，但 `search.html` 的 `initViewMode()` 实为
  `COMPACT = (localStorage.getItem('viewmode') === 'compact')`——首访用户 localStorage 为空会落 `false`（多行），
  把 `var COMPACT = true` 的默认单行直接覆盖。**后果**：全新功能无人存过 'compact'，所有人默认看到多行，R-UI-3 核心要求未生效。
- **修复**：`initViewMode` 改为 `COMPACT = (v === null) ? true : (v === 'compact')`（仅显式选过「详细」才回多行）。已合入 v1.9.24 提交 `a86b1b4` 并部署 verified。
- **方法论教训（沿用 osaka 门禁）**：AI 自称「已落地」的 PRD 必须逐行回读真实代码/DOM 证伪，不能信叙述；本例靠「首访 localStorage 空值」边界推导抓出，属门禁⑦总监反向挑战的实证。
