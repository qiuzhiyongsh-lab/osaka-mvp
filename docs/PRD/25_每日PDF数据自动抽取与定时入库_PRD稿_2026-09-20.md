## 0. 给勇哥的结论摘要（先看这段）

### 0.1 数据写在**哪两个库**？（勇哥问的核心）

| 库文件 | 路径 | 用途 | 现状 |
|---|---|---|---|
| **主库**（抓取数据） | `C:\Users\25374\WorkBuddy\2026-09-11-09-50-22\osaka-mvp\data\jproperty.db`（35MB） | REINS 抓取的房源主数据 | `properties` 4073 行；其中 `ai_extractions` 表存放**详情页「AI 解读」卡片**（目前仅 1 行样例） |
| **AI 结构库**（独立派生） | `...\osaka-mvp\data\ai_pdf_store.db`（2.5MB） | 59 列 AI 抽取字段 + 异常等级 + 雷达图 + 结论 | `ai_field_meta` 59 行 / `ai_structure` **193 行**（已由今晚的 Excel 总表灌入）/ `ai_edit_log` 0 行 |

**两个库都是现成的，不用新建。** AI 抽取结果**永远不会写回 `properties` 主表**——这正好落实勇哥「AI 读取归 AI 读取，不影响我们之前的数据算法」这条铁律。

### 0.2 关于「这到底算不算 AI」的判断

勇哥的理解 **90% 正确**，但边界要定准，否则将来会误判成本：

| 环节 | 性质 | 是否调用 AI | 是否花钱 |
|---|---|---|---|
| 读文本 PDF（pymupdf/pypdf 解析 PDF 内部文字对象） | **纯本地解析**，确定性代码 | ❌ 否 | 0 |
| 规则提取（标签定位 / 正则 / 枚举白名单 / 坪↔㎡ 交叉校验 / 月度费用勾稽） | **纯本地计算**，我写的 Python 规则 | ❌ 否 | 0 |
| 「模糊认定」（82.06mi→82.06㎡、選住中→居住中） | **一次性人类判断 → 已固化成脚本规则** | 首次是，之后否 | 0 |
| 图像 PDF → OCR（tesseract jpn + LSTM 神经网络） | **本地跑的预训练 AI 模型推理**（离线、不限量） | ✅ 是，但**本地** | 0 |
| 左右分栏版式 / OCR 失效时的视觉识别 | **云端大模型**（GLM / 混元 / 豆包） | ✅ 是，且要联网 | 几分钱/份 |

**结论**：日常每批 190 份 PDF ≈ **零 token 成本**；真正要调云端模型的只有「本地规则全失败」的少数件（实测约 5%~10%）。所以勇哥说「基本用不到 AI，那就直接做」——**方向正确，可以把本地管线做成默认，云端模型降级为兜底**。

### 1.2 本次要解决的四个缺口

| # | 缺口 | 说明 |
|---|---|---|
| G1 | **没有定时任务** | 现在 AI 提取只能手动点按钮或手动跑脚本，没有每晚自动跑的能力 |
| G2 | **没有本地优先** | 当前 `/run` **一律调云端模型**，文本 PDF 也要烧 token；应改为「本地 → 云端」三级降级 |
| G3 | **没有本地设置开关** | 抽取值时/范围/降级策略散在代码里，应进「本地设置」面板，带默认值 |
| G4 | `ai.api_key` 为空 | `config.yaml:161` 空字符串，导致 `/run` 直接返回 400，手动生成实际不可用 |

### 1.3 目标与非目标

**目标**
1. 每晚 **23:00（北京时间）/ 00:00（日本时间）起**，自动对本批 PDF 做数据抽取并入库
2. 默认走**本地零成本管线**，云端模型只在兜底时调用
3. 配置项进「本地设置」，**带合理默认值**，装上即可用
4. 详情页「AI 解读」区支持**手动生成一次**（按钮已存在，需补防重复 costly 校验）

**非目标**
- 不改 `properties` 主表任何字段
- 不做楼栋新房源抓取（那是白天 `scheduler` 的活）
- 不处理 PDF 上传到公网（沿用现有「线上不传 PDF」红线）

## 2. 术语

| 术语 | 含义 |
|---|---|
| **本地管线** | 文字层解析 + 规则提取 + tesseract OCR，**不联网、零 token** |
| **云端兜底** | 本地全失败时才调 MCP/API 大模型，可选混元 / GLM / 豆包 |
| **异常等级** | `ok` 正常 / `warn` 存疑→**红字** / `danger` 特别存疑→**红字+黄底**（勇哥 2026-09-20 拍板） |
| **三级降级** | 文字层 → OCR → 云端模型（勇哥拍板：**本地能出结果就不许调云端**） |
| **pdf_hash** | PDF 文件 sha256 前 16 位；**PDF 没变就不重跑** |
| **当日未完成** | 本轮或前轮因失败/超时/超上限而遗留的物件，**下一轮自动优先补跑**（勇哥 D3） |

## 3. 数据流向（最终态）

```
每晚 23:00 触发
   │
   ├─ 1) 扫描 data/attachments/*.pdf，筛选当日份（按 _today / 指定日）
   │
   ├─ 2) 逐个 PDF 三级降级提取
   │      ① 文字层有货 → 规则提取（本地，0 元）
   │      ② 文字层为空 → tesseract OCR + 修复 + 质量闸门（本地，0 元）
   │      ③ ①②都失败 → 云端模型（混元/GLM/豆包，几分钱）
   │
   ├─ 3) 结果经 quality gate 打 ok/warn/danger
   │
   ├─ 4) 落两个库
   │      ├─ ai_pdf_store.db → ai_structure（59 列结构化 + 雷达 + 结论）
   │      └─ jproperty.db    → ai_extractions（详情页解读卡片）
   │
   └─ 5) 写 runs 记录 + 「夜晚 AI 抽取」一轮完整日志，早上看得到
```

### 3.1 为什么定时任务「23:00 起」是黄金时段

| 理由 | 说明 |
|---|---|
| **不抢 REINS 资源** | REINS 维护时段 JST 22:00–次日 07:00，白天窗口 `07:00–22:00` 是抓取时段；AI 抽取只读**本地 PDF**，不碰平台，夜里跑零冲突零风控 |
| **不占机器白天算力** | OCR 耗 CPU，白天留给浏览器抓取 |
| **早上开工即用** | 7 点起床打开就有昨晚成果 |
| **调度机制已支持** | `core/scheduler.py:101-102` 已实现**跨午夜窗口**判定（`cur >= start or cur <= end`），`23:00–07:00` 直接可用 |

窗口建议：`schedule_ai.window = {start: "23:00", end: "06:00"}`，**与现有 REINS 抓取窗口完全独立**，互不干扰。

## 4. 定时任务设计

### 4.1 执行节奏

| 项 | 值 | 理由 |
|---|---|---|
| 触发时点 | 每日 **23:00**（本地时间 configurable） | 见 §3.1 |
| **本轮范围** | **当日新增 PDF ∪ 当日未完成的遗留项** | 勇哥 D3 拍板；遗留项**先于新增**执行（先补旧账），口径见 §14.1 |
| 执行模式 | **一次性顺序执行**（非随机间隔） | 夜间没有其他任务抢资源，顺序跑最稳 |
| 单轮上限 | 默认 300 份（可配），超出留到次轮 | 防机器负载过高 |
| 并发 | 默认 2 线程（OCR 吃 CPU，别开太多） | 可调 |
| 失败重试 | 同一 PDF 失败最多 2 次，间隔 30s | 网络抖动容错 |
| 断点续跑 | 按 `pdf_hash` + `updated_at` 记录，中途退出下次继续 | 已 constituent 就有 hash 字段 |

### 4.2 「PDF 变了才重跑」

```
入库前 SELECT pdf_hash FROM ai_structure WHERE property_no=?
   ├─ 无记录       → 新跑
   ├─ hash 相同    → 跳过（除非 force=true）
   └─ hash 不同    → 重跑（PDF 换版了）
```

**已存在「人工改过」保护不足的问题**：`ai_structure_store.upsert()` 会整体覆盖 `structure_json`（第 152-161 行），即使 `edited=1` 的字段也不会保留人工值 —— **这与勇哥「手工改过以手工为准」冲突，属于必修项**（见 §9 R1）。

### 4.3 与 BrightData 职责边界

| 任务 | 时段 | 数据源 | 写哪 |
|---|---|---|---|
| REINS 抓取（现有 `scheduler`） | 07:00–22:00 JST | 平台网页 | `properties` |
| **AI 抽取（本次新增）** | **23:00–06:00** | **本地 PDF** | `ai_structure` + `ai_extractions` |

## 5. 三级降级提取（核心）

### L1 · 文字层规则提取（默认，0 元）

适用：有文字层的 PDF（实测 123/190 ≈ 65%）
手段：标签位置切分 + 正则 + 归一化
**关键规则（今晚已验证有效）**：
- 面积：`82.06mi` / `壁芯69.00mf` / `7585mi` → `82.06㎡` / `69.00㎡` / `75.85㎡`，坪 = ㎡ ÷ 3.30578（±3% 交叉校验）
- 現況：`選住中`→`居住中`、`空家信人…`→`空家`、`賃貸中`
- 引渡：`相談…`→`相談`、`即可`→`即時`
- 広告：`掲載】要承諾`→`不可（要承認）`
- 会社住所：清洗 `二/一`→`-`、去尾部噪音
- E-MAIL：修复 `coJjp`→`co.jp`、去空格

### L2 · 本地 OCR（0 元）

适用：图像型 PDF（实测 73/190 ≈ 35%）
引擎：**tesseract 5.5.3 + jpn.traineddata**（本机已装，路径 `C:\Program Files\Tesseract-OCR\`）
流程： pymupdf 渲染 300dpi → OCR → `repair_text` 修散字/逗号 → `validate_ocr` 质量闸门
**实测产出**：501 值通过 / 232 值驳回（驳回进 `OCR待核对`，人工兜）

> ⚠️ 已验证教训：**rapidocr 中文模型会把「鉄骨造」识别成「铁骨造」**，日文场景禁用；tesseract jpn 正确。

### L3 · 云端模型兜底（几分钱）

触发条件（任一）：
1. L1/L2 提取率为 0
2. 质量闸门驳回率 > 50%
3. 检测到**左右分栏版式**（`100140804077` 这类，本地 OCR 整份错录）

模型选择（勇哥要求优先混元免费额度）：

| 优先级 | 厂商 | base_url 示例 | 说明 |
|---|---|---|---|
| 1 | **腾讯混元** | `https://api.hunyuan.cloud.tencent.com/v1` | OpenAI 兼容协议；**申请免费额度后填 `ai.api_key`** ⚠️ 具体免费模型/额度以申请时官网政策为准，**不预写死** |
| 2 | GLM（智谱） | `https://open.bigmodel.cn/api/paas/v4` | OCR 失败时的第二选择 |
| 3 | 火山方舟（豆包） | 现有默认，需付费 Key | 兜底最后一级 |

> 模型走 OpenAI 兼容协议，`ai_extract.py` 换个 `base_url` + `model` + `api_key` 即可切换，**不需要改代码**。

## 6. 本地设置（默认设置项）

新增 `config.yaml` 一节，并在「设置」面板暴露。**全部带默认值，装完即可用**：

```yaml
local_extract:              # 本地优先提取（新增节）
  enabled: true             # 总开关【默认开】
  prefer_local: true        # true=优先本地管线，本地失败才调云端【默认开】

  # —— OCR ——
  ocr_enabled: true         # 是否允许本地 OCR（false=直接跳云端，花钱）【默认开】
  ocr_dpi: 300              # 渲染 DPI
  ocr_lang: jpn             # 语言包
  ocr_timeout_sec: 60       # 单份超时

  # —— 云端兜底 ——
  fallback_model: true      # 允许调云端模型【默认开，但只在本地失败时】
  fallback_max_per_run: 50  # 单轮最多调几次云端（防账单失控）【默认50】
  ask_before_fallback: false  # 云端调用前是否先记 log【默认否】

schedule_ai:                # 每晚 AI 抽取任务（新增节）
  enabled: true             # 【默认开】
  window:
    start: '23:00'
    end: '06:00'
  max_per_run: 300          # 单轮最多处理 PDF 数
  workers: 2                # OCR 并发
  force_rerun: false        # true=忽略 pdf_hash 强制重跑
```

**设置面板暴露项**（只暴露勇哥会调的，其余留默认）：

| 自动抽取开始时间 | `schedule_ai.window.start` | 23:00 | 时间 |
| 优先本地提取（省钱） | `local_extract.prefer_local` | 开 | 开关 |
| 本地失败才调 AI 模型 | `local_extract.fallback_model` | 开 | 开关 |

### 7.3 手动生成流程

```
点「重新生成」
   ↓
① 检查 PDF 是否存在           → 无 → 置灰按钮 + 「尚未下载 PDF」
   ↓
② 检查 pdf_hash 是否已变       → 未变且有结果 → 弹窗「已有结果，重新提取？」→ 否即退出
   ↓
③ 跑本地管线（L1→L2）          → 成功 → 入库 + 展示（0 元，提示「本地提取成功，未消耗 Token」）
   ↓
④ 本地失败且 fallback_model=on → 提示「本地提取不完整（xx 项），是否调用云端模型？」
                                  → 是 → 调模型（记 cost）→ 入库 + 展示
   ↓
⑤ 展示结果（红字 / 红字黄底按异常等级渲染）
```

## 8. 展示规则（沿用勇哥 2026-09-20 拍板）

|---|---|---|
| `ok` | 常态黑字 | 正常展示、可入应用取值 |

### 13.1 `core/pdf_local_extract.py`（L1 文字层规则）

```python
# -*- coding: utf-8 -*-
"""L1：PDF 文字层 → 规则提取。本地、零成本。"""
from __future__ import annotations
import re
from typing import Any

SQM_PER_TSUBO = 3.30578

# 面积：mi/mf/m2/㎡ 变体 + 缺失小数点
_RE_AREA = re.compile(r"(\d{2,4})(?:[.,](\d{1,2}))?\s*(?:mi|mf|m2|㎡|m²|n2|ＭＦ|ＭＩ)", re.I)
# 現況枚举（含 OCR 常见错字）
_GENKYO_MAP = [("居住中", "居住中"), ("選住中", "居住中"), ("空家", "空家"),
               ("空き家", "空家"), ("賃貸中", "賃貸中")]


def fix_area(raw: str) -> tuple[float, float] | None:
    """'82.06mi' → (82.06, 24.82)；'7585mi' → (75.85, 22.94)。"""
    m = _RE_AREA.search(raw)
    if not m:
        return None
    intpart, dec = m.group(1), m.group(2)
    if dec:
        sqm = float(f"{intpart}.{dec}")
    elif len(intpart) >= 3:
        sqm = float(intpart[:-2] + "." + intpart[-2:])
    else:
        return None
    if not (15 <= sqm <= 200):      # 合理性闸门
        return None
    return round(sqm, 2), round(sqm / SQM_PER_TSUBO, 2)


def fix_enum(raw: str, pairs: list[tuple[str, str]]) -> str | None:
    """包含关键词 → 归一化为标准枚举值。"""
    for kw, std in pairs:
        if kw in raw:
            return std
    return None


def extract_from_text(text: str) -> dict[str, Any]:
    """规则提取：返回 {字段: {"value":..., "level":"ok|warn"}}。"""
    out: dict[str, Any] = {}
    area = fix_area(text)
    if area:
        sqm, tsubo = area
        out["専有面積（㎡）"] = {"value": sqm, "level": "warn"}   # 模糊认定 → 红字
        out["専有面積（坪）"] = {"value": tsubo, "level": "warn"}
    g = fix_enum(text, _GENKYO_MAP)
    if g:
        out["現況"] = {"value": g, "level": "warn"}
    # ... 其余字段规则（引渡/広告/住所/邮箱）同理，按 §5 L1 表补齐
    return out
```

### 13.2 `core/ocr_local.py`（L2 本地 OCR）

```python
# -*- coding: utf-8 -*-
"""L2：图像型 PDF → tesseract OCR（本地、零成本）。"""
from __future__ import annotations
import subprocess, tempfile, time
from pathlib import Path

TESSERACT = r"C:\Program Files\Tesseract-OCR\tesseract.exe"


def ocr_pdf_page(png_bytes: bytes, lang: str = "jpn", timeout: int = 60) -> str:
    with tempfile.NamedTemporaryFile(suffix=".png", delete=False) as f:
        f.write(png_bytes)
        p = Path(f.name)
    try:
        # tesseract <图片> stdout -l jpn --psm 6
        r = subprocess.run([TESSERACT, str(p), "stdout", "-l", lang, "--psm", "6"],
                           capture_output=True, timeout=timeout)
        return r.stdout.decode("utf-8", errors="ignore")
    finally:
        p.unlink(missing_ok=True)


def repair_text(t: str) -> str:
    """修 OCR 散字/逗号错位：'1 2 , 8 9 0円' → '12,890円'。"""
    t = t.replace(" ", "").replace(".", ".").replace("、", ",")
    t = t.replace("coJjp", "co.jp").replace("ne. Jp", ".ne.jp")
    return t
```

### 13.3 `core/ai_pipeline.py`（三级降级编排）

```python
# -*- coding: utf-8 -*-
"""P{AB|本地}三级降级编排：L1 文字层 → L2 OCR → L3 云端模型。"""
from __future__ import annotations
import hashlib, json, time
from pathlib import Path
from . import pdf_local_extract as L1
from . import ocr_local as L2
from . import ai_extract as L3_AI


def pdf_hash(path: Path) -> str:
    return hashlib.sha256(path.read_bytes()).hexdigest()[:16]


def should_rerun(no: str, h: str, force: bool, store) -> bool:
    old = store.get(no)
    if force or old is None:
        return True
    return (old.get("source_file") or "") != h     # PDF 变了才重跑


def run_one(no: str, paths: dict, cfg: dict, store, *, force=False) -> dict:
    pdf = Path(paths["attachments"]) / f"{no}.pdf"
    h = pdf_hash(pdf)
    if not should_rerun(no, h, force, store):
        return {"skipped": True, "reason": "pdf_hash 未变"}

    t0 = time.time()
    route = []
    # L1 文字层
    text, png = L3_AI.read_pdf(pdf)          # 复用现有 read_pdf（需 pymupdf）
    fields = L1.extract_from_text(text) if text else {}
    if len(fields) >= 3:
        route.append("L1:local-text")
    # L2 OCR
    if len(fields) < 3 and cfg.get("ocr_enabled", True):
        ocr_txt = L2.repair_text(L2.ocr_pdf_page(png, cfg.get("ocr_lang", "jpn"),
                                                 cfg.get("ocr_timeout_sec", 60)))
        fields = L1.extract_from_text(ocr_txt) or fields
        if fields:
            route.append("L2:local-ocr")
    # L3 云端兜底
    if (not fields) and cfg.get("fallback_model", True):
        result, meta = L3_AI.extract_property(no, paths, cfg["ai"])
        route.append(f"L3:{meta.get('model')}")
        level = "warn"
    else:
        result, level = {"fields": [{"label": k, "value": v["value"]}
                                    for k, v in fields.items()]}, "ok"
    return {"ok": True, "no": no, "route": route, "result": result,
            "level": level, "pdf_hash": h, "ms": int((time.time() - t0) * 1000)}
```

### 13.4 `core/ai_scheduler.py`（每晚 23:00）

```python
# -*- coding: utf-8 -*-
"""每晚 23:00 起的 AI 抽取任务（独立于 REINS 抓取窗口）。"""
from __future__ import annotations
import threading, time, queue
from datetime import datetime
from concurrent.futures import ThreadPoolExecutor


def _in_window(start="23:00", end="06:00"):
    now = datetime.now()
    cur = now.hour * 60 + now.minute
    sh, sm = map(int, start.split(":")); eh, em = map(int, end.split(":"))
    s, e = sh * 60 + sm, eh * 60 + em
    return (s <= cur <= e) if s <= e else (cur >= s or cur <= e)   # 跨午夜


class AIScheduler:
    def __init__(self, cfg, paths, store, log):
        self.cfg, self.paths, self.store, self.log = cfg, paths, store, log
        self._stop = threading.Event()

    def start(self):
        threading.Thread(target=self._loop, daemon=True).start()

    def _loop(self):
        ai = (self.cfg.get("schedule_ai") or {})
        w = (ai.get("window") or {})
        while not self._stop.is_set():
            if ai.get("enabled") and _in_window(w.get("start", "23:00"),
                                                w.get("end", "06:00")):
                self._run_once()
                time.sleep(3600)          # 跑完一轮睡到下一个整点
            else:
                time.sleep(300)

    def _run_once(self):
        from . import ai_pipeline
        lc = self.cfg.get("local_extract") or {}
        pdfs = sorted((self.paths["attachments"]).glob("*.pdf"))[:int(
            ai_max := (self.cfg.get("schedule_ai") or {}).get("max_per_run", 300))]
        workers = int((self.cfg.get("schedule_ai") or {}).get("workers", 2))
        stats = {"total": len(pdfs), "local": 0, "cloud": 0, "skip": 0, "fail": 0}
        with ThreadPoolExecutor(max_workers=workers) as ex:
            futs = {ex.submit(ai_pipeline.run_one, p.stem, self.paths,
                              lc, self.store): p for p in pdfs}
            for f, p in futs.items():
                try:
                    r = f.result()
                    if r.get("skipped"):
                        stats["skip"] += 1
                    elif any(x.startswith("L3") for x in r.get("route", [])):
                        stats["cloud"] += 1
                    else:
                        stats["local"] += 1
                except Exception as e:
                    stats["fail"] += 1
                    self.log(f"[AI-CRON] {p.stem} 失败：{e}")
        self.log(f"[AI-CRON] 完成：{stats}")
        return stats
```

### 14.1 D3「当日未完成」的工程口径

```
每轮待办队列 = 当日新增 PDF
             ∪ ai_structure 中 source_file(pdf_hash) ≠ 当前 PDF hash 的行
             ∪ 上轮 runs 中 status='partial' 遗留的 property_no
             − 已完成且 hash 未变的行
```

- 每轮结束写 `runs`：`total / local_hit / cloud_used / fail / 剩余未完成`
- **遗留项下一轮自动优先**（先补旧账再跑新增），避免欠账越积越多
- 单轮上限 300 是「防机器过载」，**不是裁掉任务**——超出的自动进下一轮

### 14.2 D4 抽检执行细则

| 项 | 规则 |
|---|---|
| 抽样方式 | 按「驳回原因」分层抽样（新版式的不确定性抽取），每类至少 2 条，凑满 30 条 |
| 判定标准 | 与原件 PDF 目视核对：值完全一致 = 通过；值不同但可接受（如单位格式） = 通过；错值 = 不通过 |
| 通过门槛 | **≥95%**（30 条中允许 ≤1 条不通过）则整批放行 |
| 不达标处理 | 扩到 60 条复检；仍 <95% → 该类字段降级为「永久人工」不再自动录入 |
| 产出 | 抽检表落 `OCR待核对` sheet 新增「抽样核验」列，或独立 sheet |

| 标签片段被当值（`駐車場=月額`） | 闸门只认完整标签名，不认片段 | 新增 `_FRAGMENTS` 黑名单（**不能收「有/無/可」等合法值**） |
| 历史错值永远清不掉 | 被驳回的列无产出 → 走 carry 旧值，**旧值仍是 ok** | 驳回原因回传 `upsert`：含「标签」→ danger、其余 → warn，旧值不再当 ok 用 |
