## §4.1 BUG-1「显示/隐藏其他详情」按钮失效（5WHY 诊断）

> 勇哥反馈（2026-10-06，附 2 张截图，模型未读图，按文字还原）：「这两页的两个按键就是显示和隐藏的功能，默认在查询页和详情页为打开，在对比页是关闭。现在的功能好像不好用了，再查一下。」
> 诊断纪律：证据先于结论，逐层 5WHY，每层带 file:line 证据。

### 4.1.1 现象（L0）
- 查询页 / 详情页进入时，中介信息（公司名+电话）**默认是隐藏的**，与勇哥"默认打开（显示中介）"相反。
- 切换按钮 `#agency-toggle` 文案**看不出状态 / 像坏了**：点了之后标签不随真实状态翻转，始终显示「隐藏其他详情」。
- 对比页默认隐藏（符合勇哥"对比页关闭"）—— 此页默认态正确。

### 4.1.2 5WHY 根因链（带证据）

**L1（为什么按钮像坏了）**：`#agency-toggle` 是**状态型动态按钮**（文案随 `body.hide-agency` 翻转），但它的文案会被反复重置成固定字面。
- 证据：`toggleAgency` / `initAgencyToggle`（`web/static/fieldmap.js:535-549`）用 `btn.textContent` 写状态文案（`hide-agency` 态 → `t('search.other_hide_off')`="显示其他详情"；非隐藏态 → `t('search.other_detail')`="隐藏其他详情"）。

**L2（为什么文案被反复重置）**：按钮带 `data-i18n="search.other_detail"`，而 `applyI18n()` 会**无条件**把 `[data-i18n]` 元素的 `innerHTML` 刷成字典固定值。
- 证据：`i18n.js:1807-1812 trText()` 里 `if (v != null) el.innerHTML = v`；`i18n.js:1814 applyI18n()` 遍历 `[data-i18n]` 调用 `trText`。即 `applyI18n` 一跑，`#agency-toggle` 的 `textContent` 就被覆盖回 `search.other_detail`="隐藏其他详情"，无视 `toggleAgency` 刚写的真实状态。

**L3（为什么 applyI18n 会反复跑在它身上）**：`applyI18n()` 触发时机多：① 页面加载（`i18n.js:1851`/`1864`）；② 切换语言（`i18n.js:1772` 调 `applyI18n()` + `1773` dispatch `i18n:changed`）；③ 各页 `i18n:changed` 监听器内重渲染并套用（`search.html:2319` 内 `doQuery(PAGE)`；`detail.html:792` `paintAll`；`compare.html:542`）。任一时机都会把按钮重置。
- 证据：grep 全 web 目录，`i18n:changed` 监听见上；`i18n.js:1772-1773` 为切语言路径。

**L4（为什么状态型按钮会挂上 data-i18n）**：`data-i18n` 本用于**静态文案翻译占位**，设计上就被 `applyI18n` 覆盖；但 `#agency-toggle` 是**动态状态文案**，不该用它。同文件 `search.html:1376-1377` 已明文记载：`#filterToggleTxt` **刻意不带 `data-i18n`**（否则 applyI18n 会覆盖回固定值、看不出状态），靠 `i18n:changed` 重新 sync。`#agency-toggle` **漏套用了这一保护**，直接挂了 `data-i18n`（search.html:345 / detail.html:103 / compare.html:63）。
- 证据：`search.html:345`、`detail.html:103`、`compare.html:63` 三处 `<button id="agency-toggle" data-i18n="search.other_detail" ...>`；`search.html:1376-1377` 是已知先例注释。

**L5（根因·为什么默认态还反向）**：即便修好按钮，查询页/详情页进入时仍是"隐藏中介"，与勇哥相反。`base.html:36-40` 在服务端就把 `/search` 与 `/p/`（详情页）的 `<body>` 挂上 `hide-agency`（默认隐藏），注释写着「v1.7.6：查询页/详情页默认隐藏其他详情（勇哥要求：默认就是隐藏态）」—— **与本回合勇哥最新指令（默认打开）冲突**。对比页 `compare.html:266` `var hideAgency = true;` 默认隐藏则**符合**本次要求。
- 证据：`base.html:36-40`、`compare.html:266`。

> **根因（两层）**：(a) 主要 —— 状态型动态按钮 `#agency-toggle` 误套 `data-i18n`，被 `applyI18n` 在加载/切语言/重渲染时反复覆盖文案，导致标签永远显示「隐藏其他详情」、看不出真实状态 → 用户感知"功能坏了"；(b) 次要 —— `base.html` 让查询页/详情页默认隐藏，与本次"默认打开"需求冲突。属纯前端 UI 决策冲突，**无数据层问题**。

### 4.1.3 整改项（可落地，研发直接照做）

- **G1（修根因 a）**：三页 `#agency-toggle` **去掉 `data-i18n="search.other_detail"`**（search.html:345 / detail.html:103 / compare.html:63），保留 `onclick` 与默认 innerHTML 作 fallback；文案完全由 JS 写（`toggleAgency`/`initAgencyToggle`/`cmpToggleAgency` 已用 `t('search.other_detail')`/`t('search.other_hide_off')` 写 `textContent`）。并在各自的 `i18n:changed` 回调里**重新 sync 一次按钮文案**（仿 `#filterToggleTxt` 做法）：`search.html:2319`、`detail.html:792`、`compare.html:542` 的监听器内追加 `if(window.initAgencyToggle) window.initAgencyToggle();`。
- **G2（修根因 b）**：翻转查询页/详情页默认态。`base.html:36-40` 改为：查询页/详情页**默认不挂 `hide-agency`**（即默认显示中介）；保留"用户手动切换过则由 fieldmap.js 按 localStorage 复原"的逻辑不变；同步更新该行注释为「默认显示（勇哥 2026-10-06 最新指令）」，避免后人困惑。对比页 `compare.html:266` `hideAgency = true` **维持**（符合勇哥"对比页关闭"）。
- **G3（QA 复验）**：发版后真机验证三态：① 查询页进入=显示中介 + 按钮「隐藏其他详情」；② 详情页同；③ 对比页进入=隐藏中介 + 按钮「显示其他详情」；④ 点击切换后标签随状态翻转；⑤ 切语言后标签仍正确。

### 4.1.4 影响范围与回滚
- 仅改 3 个模板 + 1 个 base 模板 + 3 处 `i18n:changed` 监听；不改数据、不改后端。回滚 = Git 退回该提交即可。

## §7 EARS 验收（每条可测）

- **Ubiquitous**：系统在所有列表卡片（详细+紧凑）与信息页，当 `floor` 有值时，楼层数字以**案A 醒目样式（18px/800/#2b6cb0）**显示于「物件种别→楼层→建筑年份」固定位置。
- **Event-driven**：当 `image_count ≤ 0`（含 0 与未知 null）时，系统不渲染「画像 N 枚」文字，仅保留 画/図/所 三标记。
- **Unwanted**：当 `broker` 为空时，列表卡片不显示中介行（不渲染空壳）。
- **State-driven**：当 `management_fee` 与 `repair_fund` 均非空且 `rent` 非空时，利回り(%) 显示计算值（保留两位小数）；否则显示空。
- **Event-driven（F8）**：当 `actual_yield_pct` 非空时，系统在该卡片 media 行（原「画像 0 枚」槽位）显示「实际回报率 X.X%」；否则该位置留空（不显示假值）。
- **State-driven（BUG-1）**：查询页与详情页进入时默认**显示**中介（按钮文案「隐藏其他详情」）；对比页进入时默认**隐藏**中介（按钮文案「显示其他详情」）；且切换/切语言后按钮文案始终与 `body.hide-agency` 真实状态一致。
- **Optional**：若 Q1-a 选中，AI 抽取新增「月額賃料」字段且覆盖 ≥ 管理费现有 69.7% 水平（目标 ≥60%）。
