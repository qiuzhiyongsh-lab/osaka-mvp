## 一、项目全貌

**一句话**：自动抓取日本 REINS 系统的大阪房源 → 存本地数据库 \+ 图纸 PDF → 网页查询/对比/分析。面向大阪房产专业人士与港澳大陆销售同事。

**技术栈**：Python 3\.10\+ / Flask（本地站点）/ Playwright 驱动 Edge（模拟人工抓取）/ SQLite / openpyxl（Excel 导出）/ YAML 配置。
**地址**：本地 `http://127.0.0.1:8765`；线上为豆包应用（wbapp\_C65E82hYRMCjxjcwW2Ph1E，web 类型）。

**两条线结构**（项目自己定的重要约定）：

|线|目录|回答的问题|
|---|---|---|
|产品线|`docs/`（PRD 00\-12 \+ UI PRD）|做成什么样、为什么|
|研发线|`core/` \+ `web/` \+ `config.yaml`|怎么做出来的|

两条线**同一仓库、同一检查点一起备份**（`checkpoint.py`），避免「代码回滚了、文档没回滚」的半截状态。

## 二、代码理解（v1\.4\.1）

### core/（抓取与数据核心，14 个模块）

|模块|职责|
|---|---|
|auth\.py|REINS 登录、会话保存/验证、过期自动重登（open\_authed\_page / try\_relogin）|
|crawler\.py|核心抓取：检索→列表解析→详情→PDF；模拟人工节奏（2\-5s \+ 8% 长停顿 \+ 12% 乱序）；两阶段下载（先全列表后全详情）；后台 PDF 下载（最多 2 并发）；实时预览/指定日期下载|
|pipeline\.py|数据入库（主档 \+ 快照 \+ 变更记录 \+ PDF），flush\_every=1 边抓边落库|
|store\.py|SQLite 存储：properties / snapshots / changes / runs / notifications / online\_stats；查询/统计/历史/进度 API|
|differ\.py|新增/变更分类（双信号：首抓 \+ previous\_price 价差）；本地快照比对|
|scheduler\.py|自动更新调度（随机间隔、窗口、跨午夜支持）|
|exporter\.py|Excel 导出、按天网页生成|
|credentials\.py|账号密码 Fernet 加密存储|
|demo\.py|离线演示数据源（字段/落盘/查询与真实完全一致）|
|wareki\.py|和暦→公元年转换（单一实现）|
|version\.py|版本单一事实来源（当前 VERSION=1\.4\.1，含完整版本注释）|
|catalog\.py / config\.py / **init**\.py|種目目录 / 配置加载|

### web/（Flask 站点）

- **页面**（8 个模板）：index 概览 / collect 数据抓取设置（4 步流程）/ search 房源查询 / compare 房源对比 / detail 房源详情 / account 账号管理 / files 本地文件 / runs 运行日志；base 公共导航

- **API**：/api/overview、/api/query、/api/compare、/api/run（手动更新/试跑）、/api/sync、/api/logs、/api/notifications、/api/history/、/api/env、/api/schedule、/api/login 等约 20 个

- **前端**：app\.js（交互\+渲染）\+ i18n\.js（简/繁/EN/日 四语）\+ fieldmap\.js（英文字段名本地化）\+ style\.css

### 数据链路（一轮抓取）

登录（会话自愈）→ 按 update\_groups 跑 6 種目（3 组检索）→ 阶段1 全列表落库（含在线总数）→ 阶段2 逐条详情 \+ PDF（后台 2 并发）→ 本地快照 → 变更比对 → 导出 Excel/按天页 → 通知。
