## 二、5WHY 根因（每一层带硬证据）

| 层 | 追问 | 证据 |
|---|---|---|
| 现象 | 线上查询页每行**没有**「打开本地 PDF」按钮、也**没有**行首 [PDF] 徽章；本地同页两张都有 | 勇哥截图 ×2 |
| W1 | 为什么线上没有？ | 模板 `search.html` 两条渲染链都靠 `r.pdf_url` 决定渲染 —— 线上拿到的 `pdf_url` 是空的。模板文件线上/本地**逐字节相同**（`app_final_v3/web/templates/search.html:1979,2048` 与本地一致） |
| W2 | 为什么线上 `pdf_url` 是空的？ | `web/app.py::_row_payload`（`/api/query`、`/api/compare` 共用）：<br>`if d.get("pdf_path"): pdf_url=本机路由` **`else: pdf_url=None`** |
| W3 | 为什么线上走 else？ | 线上 `pdf_path` **恒为空** —— 它在 `NEVER_UPLOAD_KEYS = {pdf_path, absent_runs, last_pulled_chg_date, pdf_sha256}` 里，本机路径**从不上传**（`web/app.py:55`）。线上包实测 `pdf_path` 非空 **0 行** |
| W4 | 那线上库里到底有没有 PDF 信息？ | **有**。`pdf_url` 早已移出 NEVER_UPLOAD（v1.9.62，勇哥 2026-09-23 拍板「PDF 上云」）→ 线上包 `site_data.json` **6573 行 `pdf_url` 非空**（COS 预签名直链，7 天有效） |
| W5（根因） | 为什么有数据却渲染不出？ | **`_row_payload` 的 `else: pdf_url = None` 把库里存好的云链覆盖成了 None** —— 这是本机语义（"没有本机文件就别给按钮"）被错误地施加到了线上。同一仓库的 `detail.html` 用的是正确口径：`row['pdf_url'] or 本机路由`（`detail.html:76-81 / 162-171`），所以**详情页一直是好的，只有列表页缺** |

**一句话根因**：`_row_payload` 的 PDF 直链口径没随部署形态区分，线上把 COS 云链清成了 `None`。

**实测复现**（`tools/_diag_pdfbtn_rootcause.py`，只读）：
```

样本 300140705547：库里 pdf_url = https://daban-pdf-...cos.ap-osaka.myqcloud.com/...  →  渲染后 = None
```

## 三、影响面（为什么"只有一个按钮"实际不止）

`_row_payload` 是**查询页列表 + 对比页**的**唯一数据出口**，所以同一个根因同时打掉了 5 个东西：

| 位置 | 代码 | 线上症状 |
|---|---|---|
| 查询页·展开视图底部按钮 | `search.html:2048` | 按钮整条消失 |
| 查询页·简洁视图小按钮 | `search.html:1979-1983` | 显示为**灰色禁用**（比消失更迷惑） |
| 查询页/卡片行首 [PDF] 徽章 | `search.html:1777,1952` · `prop_card.js:129` | 徽章消失 |
| 对比页「PDF」行 | `compare.html:195,456` | 显示「—」 |
| 「只看带 PDF」筛选 | `core/store.py:1778` `pdf_path IS NOT NULL` | **恒查空**（线上 pdf_path 恒 NULL） |

而**详情页 `/p/<番号>`**（`detail.html`）与**员工业务收藏卡片**走的是另一条正确口径，不受影响 —— 这也解释了勇哥"只有查询页缺"的观察。

## 四、本次改动（v1.9.108 → **v1.9.109**，4 个文件）

| # | 文件 | 改动 | 意图 |
|---|---|---|---|
| ① | `web/app.py::_row_payload` | `else: pdf_url=None` → `elif not PUBLIC: pdf_url=None` | **核心修复**：本机有落盘走本机路由；线上保留库里云链。**本机行为零变化** |
| ② | `core/store.py` | `has_pdf` 过滤：本机按 `pdf_path`、线上按 `pdf_url` | 修线上「只看带 PDF」恒空 |
| ③ | `web/static/i18n.js` | 线上按钮文案「打开本地 PDF」→「打开 PDF」 | 线上指向的是**云端** PDF，说"本地"是误导（本机文案不变） |
| ④ | `core/version.py` | 版本 1.9.109 + 变更记录 | 规矩：动 `web/static/*` 必抬版本 |

**不动**：模板（本来就对）、详情页（本来就对）、`NEVER_UPLOAD_KEYS`（安全策略不变）。
